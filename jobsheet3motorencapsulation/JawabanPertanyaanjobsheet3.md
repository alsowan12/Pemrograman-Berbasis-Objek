1. apa yang dimaksud dengan setter dan getter? 
Jawaban : getter adalah public yang memiliki tipe data return yang berfungsi untuk mendapatkan nilai dari atribut private, sedangkan setter adalah public metihd yang tidak memiliki tipe data return yang berfungsi untuk memanipulasi nilai dari atribut private.
2. apa kegunaan dari method get.Simpanan?
Jawaban : kegunaan method get.Simpanan adalah untuk mengembalikan nilai dari atribut simpanan.
3. Method apa yang digunakan untuk menambahkan saldo?
jawaban : Method yang digunakan untuk menambahkan saldo adalah method setor().
4. Apa yang dimaksud dengan konstruktor?
Jawaban : Konstruktor adalah method khusus dalam sebuah class yang secara otomatis akan dieksekusi ketika object dari class tersebut dibuat.
5. Sebutkan aturan dalam membuat konstruktor?
Jawaban : 
Aturan dalam membuat konstruktor adalah : 
1. Nama konstruktor harus sama dengan nama class
2. Konstruktor tidak memiliki tipe data return
3. Konstruktor dapat memiliki parameter
4. Konstruktor dapat memiliki access modifier

6. Apa boleh konstrutor bertipe private?
Jawaban : Tidak boleh
7. Kapan menggunakan konstruktor dengan passing parameter?
jawaban : Menggunakan parameter pada konstruktor berguna untuk menginisialisasi nilai awal dari atribut pada class

8. Apa perbedaan anatara inisialisasi atribut dan instansiasi atribut?
Jawaban : Inisialisasi atribut adalah proses memberikan nilai awal pada atribut sedangkan instansiasi atribut adalah proses membuat object dari class

9. Apa perbedaan inisialisasi method dan instansiasi method?
Jawaban : Inisialisasi method adalah proses memberikan nilai awal pada method sedangkan instansiasi method adalah proses memanggil method
